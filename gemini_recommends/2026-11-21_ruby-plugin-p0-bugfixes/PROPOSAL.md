# Proposal: Fix P0 Ruby Plugin Bugs (Rival Black Sludge, Double-Completable Trials, EventMon Boss Form Drop, Missing Mirror Switches S229-S232, Unguarded Aliases)

- **What:** Fix five verified live bugs in `Prismfall Core` and `Prismfall Trials` that break rival battles, quest reward limits, Galarian Stunfisk's boss battle, Act IV-V map event switches, and F12 soft-resets.
- **Why:** Verified still live on commit `3a520c6`:
  1. **Rival Grass starters self-damage every turn (`plugins/Prismfall Core/006_RivalStarters.rb:226-239`):** Hard Kestrel (K4-K9), Std/Casual K9, and Hard Juno (J3/J4/J7) equip `Item = BLACKSLUDGE` on `VENUSAUR` (`pbs/trainers.txt:2998-3001` et al.). `remap_item` only remaps Mega Stones, so for any player picking a Gen 2-9 starter, Venusaur swaps into a non-Poison Grass starter (Meganium, Sceptile, Torterra, Serperior, Chesnaught, Decidueye, Rillaboom, Meowscarada) that takes **1/8 max HP self-damage every turn**. Similarly, swapping `BLASTOISE` (`Nature = MODEST`, 252 SpA, `WHITEHERB`) into physical Water starters (Feraligatr, Swampert, Samurott, Quaquaval) leaves them mis-invested with a dead White Herb.
  2. **Non-repeatable Trial quests can complete twice and re-grant rewards (`plugins/Prismfall Trials/005_Trials_Quests.rb:123-142`):** `Trials.complete(id, outcome, show)` lacks a `return false if done?(id) && !q[:repeatable]` guard, so re-entering `complete` re-awards Mega Stones, Z-Crystals, money, EventMons, and Trial points. (`tools/harness/run_trials.rb:479` masked this by asserting `>= 1` instead of `== 1`.)
  3. **EventMon boss fights drop `:form`, `:ivs`, `:evs`, `:item`, `:nickname`, `:gender`, `:shiny` (`plugins/Prismfall Trials/006_Trials_EventMons.rb:122-126, 157-166`):** `apply_mon_overrides` only applies `:ability`, `:nature`, and `:moves`. As a result, `OS_STUNFISK` (`:form => 1`, Galarian Ground/Steel) spawns as **Unovan Stunfisk (Form 0, Ground/Electric)** during its boss fight, and all 6 EventMon bosses (`131_EventMons_Later.rb`, `132_EventMons_Megas.rb`) lose their 25-31 IVs and nicknames.
  4. **Missing Core mirror switches `S229-S232` (`plugins/Prismfall Core/012_Narrative_Data.rb:334-343`):** `design/FLAGS.md:189-192` specifies Core-synced switches `229` (`ROWAN_ALIVE`), `230` (`WAR_ASHKAAR_WON`), `231` (`WAR_ISENMAR_WON`), and `232` (`WAR_BOTH_BROKEN`), but `MIRROR_SWITCHES` stops at `228`, so Act IV-V map event pages conditioned on `S229-S232` will permanently evaluate `false`.
  5. **Unguarded `alias` chains (`Prismfall Core` `003_Difficulty.rb`, `005_LevelCap.rb`, `006_RivalStarters.rb`; `Prismfall Field Effects` `003_`, `005_`, `006_`, `007_`, `010_`):** Raw `alias` without `unless method_defined?` risks stack overflow on F12 soft-reset / reload (unlike `Bosses`, `Mega`, `Z-Power`, and `EBDX Bridge` which already guard theirs).
- **Where it plugs in:**
  - `plugins/Prismfall Core/006_RivalStarters.rb` (`remap_item`: map `:BLACKSLUDGE => :LEFTOVERS` when `!new_species_types.include?(:POISON)` and `:WHITEHERB => :SITRUSBERRY` unless the swapped starter learns `:SHELLSMASH`; optionally align Atk/SpA nature & EVs).
  - `plugins/Prismfall Trials/005_Trials_Quests.rb:123` (add `return false if done?(id) && !q[:repeatable]`) and `tools/harness/run_trials.rb:479` (assert `== 1`).
  - `plugins/Prismfall Trials/006_Trials_EventMons.rb:122-166` (forward `:form`, `:ivs`, `:evs`, `:item`, `:nickname`, `:gender`, `:shiny` + `pkmn.calc_stats`).
  - `plugins/Prismfall Core/012_Narrative_Data.rb:334-343` (add `229..232` to `MIRROR_SWITCHES`).
  - `plugins/Prismfall Core/*.rb` and `plugins/Prismfall Field Effects/*.rb` (add `unless method_defined?` to `alias` declarations; also move `Z_LIMIT = :side` from `Prismfall Mega/002_Mega_Battle.rb` into `Prismfall Z-Power` directly so Z-Power doesn't silently revert if Mega isn't loaded).
- **Sources:** Direct code audit of commit `3a520c6` against `design/FLAGS.md`, `design/SPINE.md`, and `pbs/trainers.txt`.
