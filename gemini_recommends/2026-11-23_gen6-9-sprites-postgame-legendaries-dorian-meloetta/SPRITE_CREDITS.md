# Pokémon Prismfall — Animated B2W2 Battle Sprite Credits (Gen 6–9, Regional Forms, Primals & Megas)

All newly installed Gen 6–9, Alolan/Galarian/Hisuian/Paldean Regional, Primal Reversion, and Mega Evolution animated battle strips in Pokémon Prismfall are **100% 2D Gen 5 B2W2-style pixel art** sourced exclusively from open-source non-commercial Pokémon Essentials & Smogon community sprite projects. **Zero 3D model renders (`ani/`) were imported.**

Copy this attribution block into Prismfall's root `CREDITS.md` / in-game Credits screen when shipping the animated sprite pack.

---

## 1. Primary Open-Source Sprite Packs Used

### Open-Source EBDX Renovation Project 4.0 (ChromeValiant)
- **Repository:** `https://github.com/ChromeValiant/Pokemon-Essentials-21-With-Unofficial-EBDX`
- **Resource Page:** `https://eeveeexpo.com/resources/1831/`
- **Role in Prismfall:** Primary unified 2D Gen 5 B2W2-style horizontal strip compilation (`1,400 / 1,402` strips in the staged `prismfall-plus-forms` pack), integrating Lucidious89's Animated Pokémon System `[SPRITES]`, Smogon 2D Sprite Projects, Aronousqui's Mega Evolutions, mangalos810's animations, the Spanish *Sprites Animados* community project, and Ghasty_001's Gen 6–9 animations.
- **License / Terms:** Free for non-commercial Pokémon fan games with full artist credits preserved below.

### Animated Sprites by Ghasty001 (Ghasty_001)
- **Repository:** `https://github.com/Ghasty001/Animated_sprites_by_Ghasty001`
- **Role in Prismfall:** Direct animated GIF → EBDX PNG strip source (supplied higher-frame 61f **Mega Altaria** Front + FrontShiny directly via `--prefer-more-frames`, plus high-polish Gen 6–9 / Hisuian animations also integrated via Renovation 4.0 including **Annihilape**, **Gholdengo** Back, **Dragapult** line, **Clawitzer**, **Dragalge**, **Heliolisk**, **Garganacl** line, **Arboliva** line, **Skeledirge** line, **Dachsbun** line, **Armarouge/Ceruledge**, **Kingambit**, **Clodsire**, **Sneasler**, **Wyrdeer**, **Hisuian Braviary/Qwilfish/Voltorb/Electrode/Sliggoo/Avalugg**, etc.).
- **License / Terms:** Explicitly *"free to use for other projects with credit"* (including base spriters credited below).

### Animated Pokémon System `[SPRITES]` (Lucidious89)
- **Resource Page:** `https://eeveeexpo.com/resources/1544/`
- **Role in Prismfall:** Core Gen 6–9 DLC + Regional + Mega animated sprite compilation incorporated into Renovation 4.0.
- **Base Architecture Credits:** Lucidious89, based on the Generation 8 Pack by **Golisopod User** and Elite Battle: DX by **Luka S.J.** (ported to Essentials v21.1 by **Manurocker95**).

### Pokémon Showdown `gen5ani` Buckets (Smogon BW Sprite Project)
- **CDN Buckets (strictly 2D `gen5ani*` only):** `https://play.pokemonshowdown.com/sprites/gen5ani/`, `gen5ani-back/`, `gen5ani-shiny/`, `gen5ani-back-shiny/`
- **Community Thread:** `https://www.smogon.com/forums/threads/smogon-sprite-project.3647722/`
- **Role in Prismfall:** Verified live CDN GIF → EBDX strip gap-filler & upstream source for Smogon 2D Gen 6–9 / Mega / Primal / Regional animations.
