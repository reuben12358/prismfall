# Prismfall badge-tier encounter OVERLAYS (Essentials v21.1 encounters format; merged as PBS/encounters_badgetiers.txt).
# Owner: Prismfall Trials (plugins/Prismfall Trials/007_Trials_BadgeTiers.rb). Design: design/BADGE_TIERS.md.
# Each section ADDS slots to a map's normal table once the player holds enough badges; it never replaces it.
#   [map, 100 + b]  -> active with b+ badges while encounter_version is 0 (the normal world)
#   [map, 200 + b]  -> same while encounter_version is 1 (Bleed-spread, Act IV+), and so on.
# A "Land" overlay also feeds LandNight/LandDay/... when the base table splits Land by time.
# A map with no base table yet gets nothing (new routes light up once pbs/encounters.txt has them).
# Levels: tier b = [cap(b) - 6, cap(b) - 3], cap(b) = level cap while holding b badges (1: 13-16, 2: 17-20, 3: 21-24, 4: 25-28).
# Weights are out of the base table's ~100, so 2-5 = rare. Only maps reached BEFORE badge b get tier b.
# Route order and names: SPINE Revision 14 + WORLD.md "Revision 14 chain" (maps.json `segment` is authoritative).
# Validate: python3 -I tools/validate_badge_tiers.py
